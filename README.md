# Микросервис данных о заказах


## Краткое описание

Этот проект представляет собой демонстрационный микросервис на **Go**, который реализует полный жизненный цикл обработки данных о заказах. Сервис слушает топик в **Apache Kafka**, получает данные о заказах, сохраняет их в базу данных **PostgreSQL** и кэширует в памяти для мгновенной отдачи через **REST API**. Проект также включает в себя простейший веб-интерфейс для отображения данных заказа по его ID.

Сервис асинхронно потребляет сообщения из **Apache Kafka**, проводит валидацию данных, сохраняет их в **PostgreSQL** в рамках транзакций и кэширует с использованием **LRU-стратегии** для предотвращения утечек памяти. Доступ к данным осуществляется через **REST API**.

## Архитектура и стек технологий

Проект построен с использованием **"Чистой архитектуры"** со строгим разделением на слои:

-   **`domain`**: Ядро приложения. Содержит бизнес-сущности и интерфейсы-контракты.
-   **`service`**: Слой бизнес-логики, не зависящий от деталей реализации.
-   **`repository` / `cache`**: Слой данных, реализующий интерфейсы домена для работы с PostgreSQL и LRU-кэшем.
-   **`delivery`**: Слой доставки (транспортный), представленный Kafka Consumer и HTTP Server.

## Стек

*   **Язык:** Go
*   **База данных:** PostgreSQL
*   **Брокер сообщений:** Apache Kafka
*   **Контейнеризация:** Docker, Docker Compose
*   **Ключевые Go-библиотеки:**
    -   `pgx/v5` - драйвер для PostgreSQL
    -   `segmentio/kafka-go` - клиент для Kafka
    -   `joho/godotenv` - управление конфигурацией через `.env` файлы
    -   `go-chi/chi`: Роутинг HTTP-запросов
    -   `pgx/v5`: Драйвер для PostgreSQL
    -   `segmentio/kafka-go`: Клиент для Kafka
    -   `go-playground/validator`: Валидация данных
    -   `gofakeit`: Генерация тестовых данных
    -   `golang-migrate/migrate`: Управление миграциями БД
    -   `uber-go/mock`: Генерация моков для тестов

## Ключевые реализованные фичи

-   **Чистая архитектура** с инверсией зависимостей.
-   **Транзакционность** при сохранении данных в PostgreSQL.
-   **LRU-кэш** для кэширования с ограниченным потреблением памяти.
-   **Валидация** входящих данных на уровне структуры и бизнес-правил.
-   **Юнит-тестирование** слоя бизнес-логики с использованием моков.
-   **Автоматизация** рутинных задач с помощью `Makefile`.
-   **Версионирование схемы БД** с помощью системы миграций.
